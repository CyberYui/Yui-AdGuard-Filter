最重要的三件事：
  1. 「检测到您的浏览器插件正在注入异常脚本」不是浏览器插件的问题，是 AdGuard 的 DNS 保护层把 cdn.wwads.cn 解析成了 0.0.0.0。加 @@||wwads.cn^ 和 @@||cdn.wwads.cn^ 到 DNS 规则即可（你已经加好了）。
  2. TT拒绝列表.txt 和 1.txt 建议删除：前者是 Android 专属语法加正则通杀，后者 2025-10-08 就停更了。
  3. 中文站拦截靠 anti-AD + EasyList China + banad（日更），比 9000 条的 1.txt 更准更新。

五、仓库里的手工规则

rules/yui-allow.txt — 通用放行

@@||playwright.nodejs.cn^
@@||www.npmjs.com^
@@||wwads.cn^
@@||cdn.wwads.cn^

已剔除你原有文件里的所有个人域名，只保留通用项。

rules/yui-cn-extra.txt — 中文站补充

www.bilibili.com###placeholder
search.bilibili.com##.search-panel
www.bilibili.com##.adblock-tips
这 3 条是从你的 ok.txt 迁移来的，未逐条真机验证：bilibili 首页是 JS 渲染，静态抓取只拿到 1,374 B，id="placeholder" / class="search-panel" / adblock-tips 都没命中。 出现误拦就删掉对应行。

六、导入步骤

  1. DNS 层放行（必做，解决 nodejs.cn 报错）
    AdGuard → 保护 → DNS 保护 → DNS 规则，添加： 
    @@||wwads.cn^
@@||cdn.wwads.cn^

    你已完成。

  2. 删掉两个本地列表：TT拒绝列表.txt、1.txt（在 AdGuard 过滤器里移除，或直接从 adguard_filter 目录删除）。
  3. 改一个本地列表：Skeyrules.txt 删掉 ||wwads.cn^ 这一行。
  4. 删掉本地副本：轻量广告拦截规则.txt 可以直接移除——217heidai 的合并规则已包含 jiekouAD（日更）。想单独订也行：https://ghfast.top/https://raw.githubusercontent.com/damengzhu/banad/main/jiekouAD.txt。
  5. 关闭一个官方列表：「Filter unblocking search ads and self-promotion」。
  6. 添加订阅：AdGuard → 保护 → 广告拦截 → 添加过滤器，把 subscriptions.txt 里的 URL 逐个粘贴。最小可用组合：anti-AD + 217heidai AdBlock Filter + AdBlock DNS + adtidy 208（前两个已含 Base / Chinese / EasyList / EasyPrivacy / jiekouAD）。
  7. 加手工规则：把 rules/yui-allow.txt 内容复制到「设置 → 过滤器编辑器 → 用户规则」。
